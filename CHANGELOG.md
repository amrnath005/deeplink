# Changelog

All notable changes to the DeepLink Pro platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-06

### Added
- **Module 1:** Next.js 16 landing page with Framer Motion, Lenis smooth scroll, and dark mode theme.
- **Module 2:** FastAPI REST backend with SQLAlchemy async PostgreSQL database sessions.
- **Module 3:** Smart Redirect Engine with 16 native app schemes, Universal Links, Android Intents, and 25+ bot detector rules.
- **Module 4:** 40+ metric browser fingerprinting collector (`fingerprint.ts`) and multi-view `/dashboard` with CSV & JSON export.
- **Module 5:** Docker multi-container setup (`docker-compose.yml`) and Nginx reverse proxy.
- **Enterprise Features:** GitHub Actions CI/CD pipeline, JWT Security utilities, User & API Key ORM models, URL Safety scanner, and Liveness/Readiness endpoints.
